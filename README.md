# pre-commit-hooks

Collection of pre-commit hooks

## Hooks available

### protect-files

Protect tracked files from being changed accidentally. This might be useful for files which are tracked by git and therefore are not handled by the .gitignore file. With this hook accidental changes of these files are prevented.

A list of glob patterns has to be be provided to define the files protected from changes. By default files will be automatically removed von staging area (this can be disabled).

The following args are available with this hook:

- `--protected-files-globs` (required): one or more globs of protected files
  - Note: pre-commit appends the filenames of staged files to the command. To separate  the list of globs from the list of filenames add '--' at the end of the args list
- `--no-unstange`: when provided the protected changed files are not automatically unstaged

#### usage

```yaml
-   repo: https://github.com/ditschi/pre-commit-hooks
    rev: v0.1.0
    hooks:
    -   id: protect-files
        # Note: pre-commit appends the fileanmes of staged files to the command.
        #       To seperate the globs from the list of filenames add a '--'
        args: ['--protected-files-globs', '.devcontainer/*', 'my/dir/*', '--' ]

-   repo: https://github.com/ditschi/pre-commit-hooks
    rev: v0.1.0
    hooks:
    -   id: protect-files
        args: ['--protected-files-globs', '.vscode/*', --no-unstage]
```

## Development

The recommended way to start the development environment is using the DevContainer in VS Code. Alternatively you can install and use `nox` and `uv` to run the same project checks locally.

The package is now configured through `pyproject.toml`.

The following commands will help you get started:

```bash
# ensure pipx is installed (already done in DevContainer)
python3 -m pip install pipx
pipx install uv
pipx install "nox[pbs]"
pipx install pip-tools

# compile a locked development requirements file (dev extra from pyproject.toml)
pipx run pip-compile --extra dev --output-file=requirements/requirements-dev-py310.txt pyproject.toml

# install pinned development dependencies
python3 -m pip install -r requirements/requirements-dev-py310.txt

# install the project into a virtual environment (editable; runtime deps are empty)
uv pip install -e .

# run all default checks
nox

# only run a specific check
nox -s tests
nox -s lint

# regenerate both lockfiles
nox -s lock

# if the `nox` executable is not found, use pipx directly
pipx run nox -s tests

# run the dev session to install pre-commit hooks
nox -s dev

# add a development dependency with uv
uv add -d <package>

## Notes on requirements and Python versions
- `requirements/requirements.txt` and `requirements/requirements-dev-py*.txt` are pinned lockfiles generated by `pip-compile`.
- Each `requirements/requirements-dev-pyXX.txt` file matches a specific Python interpreter version.
- If you add or remove supported Python versions in `nox`, regenerate the matching lockfile with `nox -s lock`.
- Update the `nox` matrix only when you want to add new supported interpreters or drop old unsupported versions.
```
